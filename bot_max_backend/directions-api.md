# API направлений

Все запросы требуют `Authorization: Bearer <token>`. Базовый путь — `/v1`.

## Открыть интерес

ID категории берётся из существующего `GET /v1/interest-categories`.

```http
GET /v1/directions?interestCategoryId=it&limit=20&offset=0
```

Ответ `200`:

```json
{
  "items": [
    {"id": "01.03.02", "code": "01.03.02", "name": "Прикладная математика и информатика"},
    {"id": "02.03.02", "code": "02.03.02", "name": "Фундаментальная информатика и информационные технологии"},
    {"id": "09.03.01", "code": "09.03.01", "name": "Информатика и вычислительная техника"},
    {"id": "09.03.02", "code": "09.03.02", "name": "Информационные системы и технологии"},
    {"id": "09.03.03", "code": "09.03.03", "name": "Прикладная информатика"},
    {"id": "09.03.04", "code": "09.03.04", "name": "Программная инженерия"},
    {"id": "10.03.01", "code": "10.03.01", "name": "Информационная безопасность"}
  ],
  "total": 7
}
```

- `query` — необязательный поиск подстроки кода/названия без учёта регистра.
- `interestCategoryId` — необязательный фильтр; без него поиск по всему каталогу.
- Фильтры работают совместно. Не требуется предварительно сохранять интерес.
- `offset >= 0`, `1 <= limit <= 100`; по умолчанию `0` и `20`.
- Сортировка: `code ASC`, затем `id ASC`. `total` — число совпадений до пагинации.
- Нет совпадений — `{"items": [], "total": 0}`.
- Неизвестная категория или некорректная пагинация — `400`.

## Сохранить и восстановить выбор

```http
PUT /v1/sessions/{sessionId}/directions
Content-Type: application/json

{"directionIds": ["09.03.04", "09.03.01"]}
```

Ответ `200` имеет ту же форму. PUT полностью заменяет выбор. Порядок сохраняется.
`{"directionIds": []}` очищает выбор. Неизвестные, пустые и повторяющиеся ID — `400`, предыдущий выбор сохраняется.

```http
GET /v1/sessions/{sessionId}/directions
```

Ответ `200`: `{"directionIds": ["09.03.04", "09.03.01"]}`; для нового пользователя — пустой массив в этом объекте.
Названия направлений фронт получает из каталога. Передавать нужно `id` из ответа каталога.

Чужая/отсутствующая сессия — `404`. Можно выбирать направления из нескольких интересов; общего лимита 5 здесь нет.
Переключение интереса не меняет сохранённый выбор. Направление может относиться к нескольким интересам.

## Данные

Flyway `V12__create_directions.sql` создаёт каталог, связи с интересами и упорядоченный выбор пользователя.
Начальный каталог содержит 22 направления для всех девяти существующих интересов; это не полный федеральный справочник.
Наличие направления в каталоге не гарантирует наличие программ вузов в текущей демо-БД.
