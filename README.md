# Менеджер баллов
## Хакатон MAX 2026, трек "Забота о людях"

**Домен приложения:** [runiversityadmission.ru](https://runiversityadmission.ru). Для авторизации открывайте мини-приложение через бота MAX.

## Назначение решения
Данный бот предназначен для абитуриентов ВУЗов, которые стремятся попасть на бюджет и имеют ИД или иные льготы. Он позволяет вручную не проверять суммарное количество баллов для разных направлений разных ВУЗов, что позволяет абитуриенту сконцентрироваться на выборе ВУЗа, а не на подсчете баллов.
### Возможности

- Сбор исходных данных через бота и редактирование баллов ЕГЭ в мини-приложении.
- Выбор направлений и расстановка их приоритетов.
- Рекомендации по программам с учётом профиля абитуриента.
- Сравнение конкурсного балла с прошлогодним проходным и просмотр расчёта.
- План «5 × 5»: до пяти вузов и пяти различных направлений в каждом.
- Ручное составление плана, автоматический подбор и дополнение существующего плана.


## Основной пользовательский сценарий

**1. Знакомство с ботом**
Пользователь находит бота в MAX и нажимает «Начать». Бот приветствует и предлагает ввести баллы ЕГЭ.

**2. Ввод баллов ЕГЭ**
Пользователь выбирает предметы, которые сдавал, и вводит баллы. Бот проверяет, что баллы не ниже минимальных порогов, и сохраняет их.

**3. Переход в мини-апп**
После ввода баллов бот предлагает открыть мини-апп. Пользователь нажимает кнопку — открывается мини-приложение с уже подставленными данными.

**4. Выбор направлений**
Пользователь просматривает каталог направлений и отмечает 1–5 интересных.

**5. Просмотр рекомендаций**
По каждому выбранному направлению пользователь видит список вузов с расчётом: его балл, проходной прошлого года. Отдельно показаны олимпиады, дающие БВИ, и баллы за индивидуальные достижения. Можно раскрыть детали — из чего сложился итоговый балл.

**6. Формирование плана**
Система предлагает черновик плана: 5 вузов, в каждом — до 5 направлений в порядке приоритета. Пользователь редактирует: добавляет, удаляет, меняет порядок.

**7. Сохранение стратегии**
Пользователь сохраняет план.

##  Состав и архитектура решения

| Каталог              | Назначение                                                             |
| -------------------- | ---------------------------------------------------------------------- |
| `bot_max_backend/`   | Бот MAX и REST API: Java 21, Spring Boot, Spring Security, JPA, Flyway |
| `bot_max_frontend/`  | Мини-приложение: React, TypeScript, Vite, Redux Toolkit, MAX UI        |
| `nginx/`             | HTTPS и проксирование фронтенда, API и webhook                         |
| `.github/workflows/` | Автоматизация развёртывания frontend и backend                         |
| `docker-compose.yml` | Серверный запуск приложения, PostgreSQL, Redis и nginx                 |

Система состоит из 5 компонентов:
1) бэкенд-часть
2) фронтенд-часть
3) прокси - nginx
4) PostgreSQL - БД для долговременного хранения данных
5) Redis - для хранения статуса текущей сессии, позже можно добавить кеширование результатов для пользователя

```text
MAX
│
└── мини-приложение/чат-бот
        │
        ▼
      nginx
        │
        ▼
      Backend
     │       │
     ▼       ▼
PostgreSQL  Redis
```


## Запуск через Docker

```sh
docker compose -f docker-compose.local.yml up -d --build
```

## Работа с данными
Данные были искусственно получены с информационных источников ВУЗов и добавлены через миграции (по направлениям, проходным баллам, правилам )

| Данные | Источник | Объём                                                                  |
|---|---|------------------------------------------------------------------------|
| Перечень олимпиад и их уровни | Приказ Минобрнауки № 669 от 30.08.2025, rsr-olymp.ru | 21 олимпиада (ВсОШ и 20 из перечня РСОШ), 45 профилей с уровнями I–III |
| Проходные баллы | tabiturient.ru: бюджет, очная форма, 2025 год | 24 вуза Москвы, 101 программа  |
| Льготы по олимпиадам и баллы за ИД | Правила приёма 2026 с сайтов МГУ, ВШЭ, МФТИ, МГТУ им. Баумана | Реальные правила у 4 вузов, у остальных демонстрационные               |
| Минимальные баллы ЕГЭ | Минобрнауки | 11 предметов                                                           |


## Пошаговый сценарий проверки

1. Откройте бота `@t722_hakaton_max_bot` в MAX.
2. Нажмите «Начать».
3. Введите баллы ЕГЭ (например: русский 80, математика 75, информатика 85).
4. Нажмите «Открыть мини-апп».
5. В мини-аппе выберите 1–2 направления.
6. Посмотрите рекомендации по каждому направлению.
7. Сформируйте план 5×5.
8. Сохраните план.

**Ожидаемый результат:** бот присылает в чат итоговую стратегию.
